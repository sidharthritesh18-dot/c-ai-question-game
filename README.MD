\# C AI Question Game



A beginner-friendly quiz game written in C.



The quiz questions and explanations are created with assistance from AI while the game logic is programmed in C.



\## Features



\- Three multiple-choice questions

\- Answer checking

\- Score calculation

\- Final score display

\- Beginner-friendly C code



\## How to Run



Compile the program:



```bash

gcc main.c -o question-game
